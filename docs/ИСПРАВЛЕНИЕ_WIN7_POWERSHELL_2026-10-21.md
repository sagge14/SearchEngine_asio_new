## Диагноз

Пользователь передал снимок Windows 7 x86: проверка пакета завершается ошибкой
`System.Security.Cryptography.SHA256Managed` — отсутствует метод `Dispose`.
После неё отображаются `Package verification failed` и `Installer exit code: 1`.
Прежнее исправление очистки сработало: BAT сохранился и показал итоговый код.

В `Verify-Package-Windows7.bat:19` освобождение SHA-256 выполнялось через
`$hash.Dispose()`. В старом .NET метод реализован через интерфейс и не доступен
таким публичным вызовом. Проверка ошибочно отклоняла даже исправный пакет после
чтения файлов. Это подтверждено повтором прежнего embedded-скрипта на локальном
PowerShell **2.0**, CLR **2.0.50727.9179**: та же ошибка, exit 1.

Заменён только вызов освобождения hash-объекта на `$hash.Clear()` и уточнён
комментарий о совместимости. SHA-256, проверка путей, кодировка UTF-8, запрет
токенов внутри поставки и отклонение повреждённых файлов сохранены.
Устанавливать новый PowerShell/.NET на целевом ПК для этого исправления не нужно.
API-контекст: [Microsoft, HashAlgorithm.IDisposable.Dispose для .NET 3.5](https://learn.microsoft.com/en-us/dotnet/api/system.security.cryptography.hashalgorithm.system-idisposable-dispose?view=netframework-3.5).

Первый этап проверял рабочие BAT на современном PowerShell 5.1 и подставных
командах. Он не покрывал этот API старого CLR. Новый тест запускает точный
PowerShell-код из настоящего BAT на обоих реальных runtime, без эмуляции.
