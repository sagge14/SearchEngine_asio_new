## Исправление упаковки и продолжение выпуска

Первая попытка остановилась в Get-SearchEngineServiceSourceFingerprint: Git возвращал русские имена в кавычках с восьмеричными escape-последовательностями. Они не проходили исключение прежних tutorials и приводили к Illegal characters in path. Для локального вызова Git добавлен core.quotepath=false; настройки Git пользователя не менялись. Текущий tutorials остаётся источником отпечатка, включая новые и переименованные файлы. Прошли все 49 существующих ArchiveE2EStandRelease.Tests, включая разбор PowerShell и детерминированность отпечатка.

Повтор выполнен с -SkipVersionBump. При переносе готовой папки Windows 7 возник отказ Move-Item; повторён только этот вариант с прежней версией 0.1.95, после чего выпуск завершился успешно. Уже опубликованные x64 и современный x86 повторно не выпускались.
