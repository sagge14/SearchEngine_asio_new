# Предложение: отдельная утилита `BackupRestore`

Утилита восстановления должна быть отдельной целью сборки и по умолчанию
работать с хранилищем только на чтение. Первая версия может быть консольной:
так проще проверить алгоритм и использовать её из аварийной WinPE/другой
машины. Графический интерфейс можно добавить поверх того же ядра.

## Консольный интерфейс

```text
BackupRestore targets --root F:\AutoPadEconomicalBackups
BackupRestore points --target <каталог-цели>
BackupRestore show --point <manifest.json>
BackupRestore verify --point <manifest.json>
BackupRestore plan --point <manifest.json> --to D:\Recovered\BASES_PRD
BackupRestore restore --point <manifest.json> --to D:\Recovered\BASES_PRD
BackupRestore restore --latest --target <каталог-цели> --to D:\Recovered
BackupRestore file --point <manifest.json> --path ARCHIVE.db3 --to D:\Recovered
```

`plan` ничего не пишет: показывает число и объём файлов, откуда будет взята
каждая версия (`current` или `objects`), а также отсутствующие и повреждённые
объекты.

`verify` проверяет наличие, размер и SHA-256 всех файлов выбранной точки.

`restore` сначала собирает данные во временный соседний каталог, проверяет
полученный комплект и только затем переименовывает его в итоговый. По
умолчанию существующий каталог назначения не перезаписывается. Для этого
нужен отдельный явный параметр `--overwrite`.

## Возможный графический интерфейс

Главное окно:

- слева — найденные цели (`BASES`, `BASES_PRD`, `F12`, `OTPRAVKA`, `TVRD`);
- в центре — точки, отсортированные по реальной дате, с колонками «период»,
  «полнота», «файлов», «требуется прочитать»;
- справа — состав выбранной точки и результат проверки;
- снизу — каталог назначения и кнопки «Проверить», «Показать план»,
  «Восстановить всё», «Восстановить выбранные файлы».

Особый пункт «Текущее состояние» должен указывать на `current\data` и
позволять восстановить его без сборки из истории.

Перед записью в рабочий каталог окно должно явно предупредить, что программы
и сетевые пользователи должны быть отключены. Безопасный сценарий по
умолчанию — восстановление в новый каталог с последующей ручной заменой.
