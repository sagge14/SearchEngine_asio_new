## Причина и исправление

Общий шаблон `Install-SearchEngineService-Windows7.bat` используется для x64,
x86 и x86-Windows7. При ошибке до `INSTANCE_READY` переменные `CONFIG_TEMP`,
`ENDPOINT_TEMP`, `HELPER_OUTPUT` ещё не были заданы. Обработчик `FAILED`
выполнял `del /Q ""`. CMD трактует пустой путь как текущую папку и удаляет
находящиеся в ней файлы. При запуске из папки пакета удалялись также сам
установщик и вызывающий BAT. После возврата `CALL` CMD не мог дочитать BAT,
поэтому заключительный `pause` не удерживал окно.

До исправления настоящий BAT запущен только в отдельной одноразовой папке
с заведомо неполным пакетом. Исчезли контрольный `sentinel.txt`, установщик
и обёртка; результат: `ERROR: The portable package is incomplete` и
`The batch file cannot be found`. Это подтверждает механизм потери файлов,
но не устанавливает первоначальную причину отказа на компьютере пользователя.

Исправления:

- Все четыре временных пути создаются в начале BAT, до разбора аргументов
  и любых предварительных проверок: шаблон, строки 5–10.
- `FAILED` и `CANCELLED` вызывают общую `CLEANUP_TEMPS`; перед каждым `del`
  проверяются непустая переменная и отсутствие каталога по этому пути:
  строки 965, 978, 983–989.
- Обёртка выводит фактический код возврата и приглашение к `pause` встроенными
  командами CMD. Для заключительного сообщения больше не требуется запуск
  SearchEngineConfig, который при раннем отказе может отсутствовать или не
  загружаться из-за CRT: `Local-Machine-Install-Windows7.bat`, строки 7–12.
- Добавлены `ServiceInstallerSafety.Tests.ps1`, `FakeInstallerConfig.cs`
  и регистрация `ServiceInstallerSafety_test` в CMake. CMake не запускался;
  тесты выполнены напрямую через Windows PowerShell 5.1.

Ранее успешный проход мог скрывать дефект: после `INSTANCE_READY` временные
переменные уже имели значения. Одинаковая версия сама по себе не объясняет,
почему на конкретном ПК впервые возник предварительный отказ.

## Проверка на компьютере пользователя

Для Windows 7 x86 нужен именно `SearchEngineService-x86-Windows7-0.1.96.zip`.
Обычный `SearchEngineService-x86` предназначен для Windows 10 / Server 2016+.

1. Распаковать исправленный Windows7 ZIP целиком в отдельную новую папку;
   не использовать повреждённый остаток старой распаковки.
2. Запустить `Verify-Package.bat`, затем `Local-Machine-Install.bat`
   через «Запуск от имени администратора».
3. Проверить, что файлы папки сохранились, установка создала и запустила
   `SearchEngineService-2026`, а окно дошло до итогового сообщения.
4. Если установка завершилась ошибкой, передать весь текст над строкой
   `Installer exit code`. Обёртка теперь сохраняет окно и код возврата.
5. Если служба запустилась, проверить подключение клиента и обычный поиск.

Реальные Win7 SP1/KB/CRT, установка службы и firewall, выпуск рабочего токена,
первичная индексация настоящих данных и подключение клиента здесь не
проверялись. Точная причина исходного предварительного отказа на целевом ПК
остаётся неизвестной. Проверки подставных команд и `/validate` этого не заменяют.
