Con: Константы и неизменяемость - Подробный конспект

О разделе: Раздел Con содержит рекомендации по использованию констант и неизменяемости. Неизменяемые объекты проще для понимания и рассуждений, они безопасны для многопоточности и предотвращают ошибки.

Con.1: По умолчанию делайте объекты неизменяемыми

❌ Как НЕ надо

// Плохо: изменяемые переменные по умолчанию
for (int i : vec) {  // i может быть изменён
    i = 42;  // изменяем значение
    process(i);
}

int value = 10;
value = 20;  // изменяем значение

✅ Как надо

// Хорошо: const по умолчанию
for (const int i : vec) {  // i неизменяем
    // i = 42;  // ошибка компиляции
    process(i);
}

const int value = 10;
// value = 20;  // ошибка компиляции

Con.2: По умолчанию делайте функции-члены const

❌ Как НЕ надо

// Плохо: функция не помечена const
class Point {
    int x, y;
public:
    int get_x() {  // не const, хотя не изменяет объект
        return x;
    }
};

✅ Как надо

// Хорошо: const функция-член
class Point {
    int x, y;
public:
    int get_x() const {  // const, не изменяет объект
        return x;
    }
    
    void set_x(int new_x) {  // не const, изменяет объект
        x = new_x;
    }
};

// Использование:
const Point p{10, 20};
int x = p.get_x();  // ОК, get_x() const
// p.set_x(30);  // ошибка, set_x() не const

Con.3: По умолчанию передавайте указатели и ссылки на const

❌ Как НЕ надо

// Плохо: неконстантные параметры
void process(int* data) {  // может изменять data
    *data = 42;
}

void print(std::string& str) {  // может изменять str
    std::cout << str;
}

✅ Как надо

// Хорошо: const параметры по умолчанию
void process(const int* data) {  // не может изменять data
    // *data = 42;  // ошибка компиляции
    std::cout << *data;
}

void print(const std::string& str) {  // не может изменять str
    std::cout << str;
}

// Только для входно-выходных параметров используйте неконстантные:
void modify(int& value) {  // явно изменяет значение
    value = 42;
}

Con.5: Используйте constexpr для значений, которые могут быть вычислены на этапе компиляции

❌ Как НЕ надо

// Плохо: вычисление во время выполнения
double calculate_pi() {
    return 3.14159265358979323846;
}
const double pi = calculate_pi();  // вычисляется во время выполнения

int factorial(int n) {
    return (n <= 1) ? 1 : n * factorial(n - 1);
}
int fact_5 = factorial(5);  // вычисляется во время выполнения

✅ Как надо

// Хорошо: вычисление на этапе компиляции
constexpr double calculate_pi() {
    return 3.14159265358979323846;
}
constexpr double pi = calculate_pi();  // вычисляется на этапе компиляции

constexpr int factorial(int n) {
    return (n <= 1) ? 1 : n * factorial(n - 1);
}
constexpr int fact_5 = factorial(5);  // вычисляется на этапе компиляции

// Можно использовать в константах времени компиляции:
std::array<int, fact_5> arr;  // размер массива известен на этапе компиляции

Заключение

Ключевые принципы раздела Con (Константы и неизменяемость):

  • Неизменяемость по умолчанию: Делайте объекты const по умолчанию
  • const функции-члены: Помечайте функции-члены const, если они не изменяют объект
  • const параметры: Передавайте параметры по ссылке/указателю на const по умолчанию
  • constexpr: Используйте constexpr для вычислений на этапе компиляции
  • Безопасность: Неизменяемые объекты безопасны для многопоточности

Конспект создан на основе C++ Core Guidelines. Полный документ: https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines
