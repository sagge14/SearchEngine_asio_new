Установка, обновление и удаление серверной службы

Быстрая установка без вопросов: Local-Install-With-Auth.bat — с авторизацией; Local-Install-Without-Auth.bat — без ключей и токенов. Запустите нужный файл; при запросе Windows подтвердите права администратора. Год, свободный порт, индексация и запуск службы выбираются автоматически. Это новая местная установка; для обновления существующей службы используйте обычный Install.

В обычном мастере режим выбирается вопросом; быстрые батники задают его по своему названию. При обновлении обычный мастер предлагает сохранённое значение. Порядок выбора и переключения.

Быстрый маршрут: Установить · Обновить · Удалить сервер

Используйте полный переносимый комплект подходящей архитектуры: BAT, app, data, tools, prerequisites и tutorials. Не запускайте отдельный файл из ZIP. Пояснения меню всех запускателей: 14 батников серверного пакета.

Выбрать способ установки

  • Local-Install-With-Auth.bat — новая местная установка текущего года с авторизацией; Local-Install-Without-Auth.bat — без ключей и токенов. Запустите один выбранный файл и подтвердите запрос прав Windows, если он появился. Режим задаётся именем батника. Если служба или непустые каталоги уже есть, быстрый установщик останавливается. Для обновления нужен обычный Install.
  • Install-SearchEngineService.bat — новая установка с параметрами либо обновление экземпляра. Выберите язык, имя и параметры, проверьте результат.

Права администратора требуются для операций со службой. На целевом ПК не нужны исходники и компилятор. Просмотр списка служб, регистрация токена и проверка пакета используют комплектный Windows PowerShell.

Установщик проверяет VC++ Runtime до запуска помощника, при отсутствии ставит комплектный redistributable. Если helper способен работать с поставляемыми рядом DLL, установка может продолжиться после ошибки системной установки Runtime. Полностью без подходящих DLL helper не запускается. Выбирайте комплект с явно указанной минимальной версией Windows; для варианта Windows 7 требуется SP1.

Экземпляры и параметры

Имя экземпляра: 1…32 латинских букв, цифр, дефисов и подчёркиваний; первый символ буква или цифра. default использует службу SearchEngineService и стандартные каталоги; archive — SearchEngineService-archive и отдельные каталоги программы и данных. Каждому экземпляру нужны собственные порт, данные и индекс. Имя Windows-службы не передаётся клиенту по сети.

Install-SearchEngineService.bat archive
Stop-SearchEngineService.bat archive
Start-SearchEngineService.bat archive
Restart-SearchEngineService.bat archive

Без аргумента управляющие BAT предлагают выбрать экземпляр. Явное имя не заменяется другим сервером. ServiceInstance.cmd задаёт предлагаемое имя; Resolve-ServiceInstance.cmd — служебный помощник.

Enter принимает показанное значение конкретного вопроса. Для новой установки предлагается SQLite-каталог; при обновлении — импортированный режим. Год 2000…2099, порт 1…65535, таймаут файла 10…600 секунд; прочие диапазоны и пути перечислены в справочнике настроек. /validate только проверяет пакет; /SkipVcRedist рассчитан на заранее обеспеченный Runtime, иначе установка не продолжится.

Результат местной установки

Оба быстрых установщика создают годовую службу, выбирает первый свободный порт начиная с кандидата шаблона, формирует sqlite-каталог, scan_on_startup=false и отключённое изменение краткого содержания PRM. Вариант With-Auth создаёт токен текущего ПК, Without-Auth пропускает ключи и токен. Затем оба выполняют отдельную синхронную первоначальную индексацию, запускают службу и проверяют RUNNING + PONG.

Запишите итоговые год, порт, имя службы, путь журнала и client-endpoint.txt. В варианте с авторизацией фиксированный пароль создаваемого упрощённым установщиком хранилища — 12345678; существующее хранилище с другим паролем не перезаписывается. Закрытые ключи пользователям не передаются.

Ошибка первичной индексации не скрывается: служба может быть запущена и проверена, но BAT возвращает код 20 и показывает команду повторного прохода. Исправьте учебные корни/доступ и выполните показанную команду. RUNNING не подтверждает готовность всего индекса. Ошибка выпуска токена может удалить только новую установку, оставляя общее хранилище и токен, которыми могут пользоваться другие компоненты.

Обновление установленной службы

Обновляйте выбранный экземпляр штатным Install-SearchEngineService.bat из полного нового комплекта. Сохраните прежний portable-комплект и полную копию установки. Быстрые локальные батники для обновления не предназначены.

До замены сохраните программу, рабочие данные и внешние источники. Полный экспорт Install содержит application и data выбранной установки. Внешние документы, PRM/PRD, опись, F12 и выходные папки в него автоматически не добавляются. Копия установки может обращаться к тем же внешним данным. До проверки остановите их изменение и подготовьте согласованные копии; не копируйте один файл живой SQLite без её штатного механизма резервирования или остановки всех пишущих процессов.
Этот порядок относится к обычной установке в стандартных каталогах. Install вычисляет пути ProgramFiles/ProgramData по имени экземпляра. Он не обновляет автоматически активный архивный комплект или службу, перенесённую под другой корень. Сначала проверьте фактический путь запуска и рабочий каталог данных. Для архивной службы выполните поддерживаемый возврат в исходные места и убедитесь, что они совпадают со штатными путями. Для другого размещения отдельно согласуйте порядок; не запускайте Install вслепую.
  1. Завершите пользовательские операции. Запишите имя службы, год, фактический порт, каталог программы и рабочий каталог данных. Сохраните прежний полный пакет и согласованные копии внешних данных.
  2. Распакуйте новый комплект целиком и проверьте его Verify-Package.bat. Не заменяйте EXE/DLL вручную в работающей службе.
  3. Запустите Install от администратора, выберите действующий экземпляр и «1 — переустановить/обновить». Выберите «1 — полная копия», укажите место вне заменяемых каталогов с достаточным запасом. «Только настройки и журналы» и отказ от экспорта не заменяют полную копию.
  4. Проверьте параметры и дождитесь итога. Перед заменой Install штатно останавливает службу и выполняет полный экспорт. Сохраните показанный backup_path и проверьте наличие application, data и backup-info.txt.
  5. Проверьте версию, вход, настройки, текстовый и SQL-поиск, открытие документов, опись/F12, загрузку и остальные используемые функции. PONG подтверждает ответ процесса, а не полноту данных и работу всех функций.
  6. После проверки продолжайте работу обновлённой службой. Сохраните прежний пакет, экспорт и внешние копии на выбранный период наблюдения. Удаляйте их только после проверки всех функций и стабильной работы, убедившись, что они больше не используются.

Обычное обновление сохраняет ProgramData: индекс, разрешения, журналы, пользовательские ignore.txt, prefix_map.json и неизвестные файлы. Settings формируется из нового шаблона с импортом прежних значений и ответами диалога; приоритет описан в совместимости. OEM866.INI и client-endpoint.txt входят в управляемый откат. Сохранение рабочего каталога данных при обновлении не заменяет отдельный экспорт.

Возврат к предыдущей версии

Если установка не прошла запуск/PONG, Install пытается вернуть прежние программу, управляемые файлы, порт брандмауэра и регистрацию службы. Прочитайте итог отката: успешное завершение нельзя предполагать по наличию папки. Этот откат не восстанавливает все изменения внешних данных.

Для возврата после уже успешного обновления завершите операции и остановите новую службу. Сохраните текущее состояние. Используйте прежний полный пакет и его Install для того же стандартного экземпляра. Если требуется прежнее состояние данных, восстановите согласованную копию data и затронутых внешних источников при остановленной службе и остановленных пишущих приложениях, затем проверьте запуск и все функции. Перед этим проверьте совместимость форматов: старый EXE может не читать новый формат базы или настроек. Автоматического мастера импорта полного экспорта в текущем комплекте нет; восстановление и выбор общей точки данных выполняет администратор. Одновременно две службы на одних данных не запускайте.

Остановка, запуск и применение настроек

Stop и Restart ждут штатную остановку до 1800 секунд; принудительного завершения в этих управляющих BAT нет. Start и Restart ждут запуск и PONG на порту установленного файла. Start уже работающей службы проверяет ответ, но не применяет вручную изменённый файл. Stop → Start создаёт новый процесс.

Установленный тип запуска Automatic/Delayed Start после Stop не меняется: после перезагрузки Windows служба может запуститься снова. Для длительного отключения настройте тип запуска в Windows отдельно.

Configure — путь для изменения рабочего JSON: временная копия, проверка, подтверждение, штатный перезапуск, PONG и откат при ошибке. При смене порта обновляет правило брандмауэра и подсказку, но не Settings.db3 клиента. После ручной правки это нужно сделать отдельно. Подробности применения.

Полное удаление

До подтверждения сохраните полную копию и проверьте конкретные пути. Uninstall уничтожает выбранные программу и рабочие данные; у архивной службы — весь активный архивный комплект с документами и базами. Для временного выключения используйте Stop.

Uninstall-SearchEngineService.bat предлагает экземпляр, экспорт и отдельное окончательное подтверждение. Он удаляет выбранную службу, её правило брандмауэра, программу и рабочие данные. Для замороженного сервера целевой каталог — весь активный архивный комплект, включая документы и базы. Перед подтверждением прочитайте именно показанные пути.

Индекс и базы не сохраняются автоматически после полного удаления. При экспорте проверьте копию. Скрипт ждёт завершения процесса и повторяет очистку; при занятых файлах закройте программы просмотра каталогов/баз и используйте повторную попытку. Регистрация удаляется после файлов. Окна services.msc и другие консоли могут удерживать регистрацию «помечена на удаление»; закройте их и повторите проверку. Последняя диагностика: %TEMP%\SearchEngineService-Uninstall-last.log; итоговое окно закрывается клавишей 0.

Ключи издателя и токен пользователя удаляются отдельно Remove-SearchEngineAuthKeys.bat; по умолчанию остаются. Проверяйте, используют ли их другие службы. Переустановка, Stop и полное Uninstall — разные операции.

Архив и возврат

Archive умеет перенести год без службы или переместить установленную службу и заморозить. Во втором случае старое место очищается только отдельным этапом после проверки. Особые сценарии декабрьской PRD и TverdakManager, перекрывающиеся источники и поздняя очистка подробно сохранены в заморозке и разморозке. Не используйте Uninstall вместо проверки и очистки прежнего места.
