Файлы данных, доступ и связанные настройки

Файлы auth_clients.sqlite и issuer-public.pem используются только при authentication_mode=required. В none сервер их не открывает. Два режима доступа.

Быстрый маршрут: Подключить дополнительный ПК

Каждый экземпляр имеет свой каталог данных. Его фактический путь определяется регистрацией службы, в том числе после архивации. Просмотр служб показывает путь Settings.json.

Доступ и учётная запись

Служба установщика работает под LocalSystem. Для UNC-корней синтаксически правильный путь ещё не подтверждает доступ к сетевой папке и её правам. Для локальных папок нужны права чтения документов и записи в каталог данных; для загрузки — запись в выбранные выходные папки. Папки F12/описи/разноски могут отсутствовать, пока функция не используется; её ошибка появляется при обращении.

Для общего доступа используйте заявку и ответ. Для защищённых источников клиенту нужен подходящий токен и включённое разрешение каждого источника. На открытых источниках токен не проверяется. Открытый ключ без записи устройства не даёт доступа. ПК-токен находится в профиле того пользователя Windows, который запускает клиент; запуск утилиты под другим пользователем использует другой профиль.

Карта пользовательских пакетов prefix_map.json

Это одноразовый буфер. GET_ATTACHMENTS удаляет исходную папку после чтения файлов, до сериализации и передачи ответа. В клиенте запрос выполняется ещё до выбора локальной папки: отмена выбора тоже не возвращает пакет. Ошибка передачи или записи может оставить пользователя без файлов. Сначала сохраните отдельную копию пакета; не направляйте карту на весь архив или единственную копию документов.

Файл находится рядом с рабочим Settings.json. Поле prefix — строка общего начала пути, map — объект, где ключ — точное имя пользователя; в режиме без авторизации используется только общее имя unauthenticated_user, значение — добавляемая строка. Это не значение server_id и не имя Windows-службы. Регистр имени имеет значение. Пути собираются простым соединением строк, поэтому разделитель укажите явно.

{
  "prefix": "E:\\Учебные_пакеты\\",
  "map": { "Ivanov": "пакет_Иванова" }
}

Для Ivanov получится E:\Учебные_пакеты\пакет_Иванова. Можно оставить prefix пустым, а в map записать полный путь. Комплектный нейтральный шаблон — {"prefix":"","map":{}}; имя без записи получает ошибку «оператор не зарегистрирован», а не пакет другого пользователя. Значения map должны быть строками; JSON с неверным форматом выдаёт ошибку конфигурации.

Файл перечитывается на каждый запрос «Сохранить приложения»: перезапуск только для этой карты не требуется, уже начатый запрос использует прочитанные значения. Укажите отдельную папку буфера, которую допустимо очистить целиком, и проверьте учебный пакет с вымышленным пользователем. Перед использованием учтите предупреждение об одноразовой выдаче выше.

Исключения подразделений ignore.txt

По одной строке UTF-8 на подразделение. Пустые строки игнорируются, краевые пробелы убираются; сравнение точное, с учётом регистра. Начальный список: ИСХ и ТРАНЗИТ. Если файла нет, создаются эти значения. В данных подразделения перед сравнением убираются точки с запятой.

Список используется в обработке новых файлов только при server_mode=active и enable_prm_short_content_autodetect=true. Исключение предотвращает автоматическую запись описи подразделения; оно не отключает индексацию текста и не гарантирует запрет изменения краткого содержания PRM, которое выполняется раньше этой проверки.

Новый обработчик читает файл при обработке события, поэтому изменение может подействовать без перезапуска; уже подготовленное отложенное действие может использовать ранее прочитанный экземпляр списка. Чтобы исключить смешение старых и новых настроек, штатно остановите процесс, отредактируйте список и запустите его. Проверка — новый файл отдельного учебного подразделения и журнал record/watcher; рабочие базы для проверки не меняйте.
