Все перечисленные поля находятся в объекте config файла Settings.json. Открыть установленный файл: Configure-SearchEngineService.bat → выбрать службу. Файл data\Settings.json распакованного комплекта — шаблон для установки; его правка не меняет уже работающий сервер.

Когда настройки действуют

  1. Мастер открывает временную копию рабочего файла. Сохраните её и закройте редактор.
  2. Дождитесь проверки; при ошибке откройте копию повторно или отмените.
  3. Выберите «1 — применить». Мастер останавливает службу, публикует файл, запускает новый процесс и проверяет RUNNING и PING/PONG.
  4. При смене порта мастер обновляет client-endpoint.txt и правило брандмауэра. Адрес/порт в базе клиента измените отдельно.

Данные в памяти обновляются при старте нового процесса. Автоматического перечитывания файла во время работы нет. При ручной правке нужны Stop → Start, проверка брандмауэра и параметров клиента. Start уже работающей службы сам по себе не перезапускает процесс. Ошибка применения запускает возврат прежних настроек; читайте итог, не закрывайте мастер во время остановки.

Остановка закрывает соединения и дожидается уже поставленных задач. Новый запрос или подготовленный клиентом пакет автоматически под новую конфигурацию не перестраивается. После перезапуска проверьте авторизацию, повторите поиск, затем подготовьте сохранение заново.

Значения не всегда одинаковы. В таблицах отдельно указаны значение в шаблоне комплекта и результат отсутствия поля при прямом запуске. При штатной упаковке год и последняя цифра порта шаблона уточняются по году выпуска; установщик рассчитывает потоки и предлагает параметры. При обновлении выбирается сначала явный ответ диалога, затем существующая установленная настройка, затем значение нового шаблона. Не удаляйте поля ради восстановления исходных значений.

Диапазоны ниже соответствуют штатной проверке Configure/Install; прямой запуск некоторых полей проверяет менее строго. Старые имена, перезапись и приоритеты: совместимость настроек. Практические изменения: примеры настройки сервера.

Основные

Поле и допустимые значенияПример из шаблона / отсутствиеНазначение и связиПроверка после применения
year

Строка из четырёх цифр 2000…2099 для мастера

Шаблон: "2026"

Если нет: Обязателен

Выбирает имена месячных баз 01…13-ГОД.db3, описи и маршрутов ГОД.db; не переносит документы. При прямом старте проверяется непустая строка, пользуйтесь проверкой мастера.Сверьте год, найдите учебную карточку и получите опись с этого источника.
asio_port

Целое 1…65535

Шаблон: 15006

Если нет: 15001

TCP-порт службы; клиент использует то же число. На одном ПК экземплярам нужны разные свободные порты. Старый port имеет приоритет, если присутствует.List-SearchEngineServices показывает фактический порт; подключите клиент. После ручной правки отдельно согласуйте правило брандмауэра и client-endpoint.txt.
index_roots

Непустой массив абсолютных Windows-путей; локальные или UNC

Шаблон: ["D:\\ЯНВАРЬ", "D:\\ФЕВРАЛЬ", "D:\\МАРТ", "D:\\АПРЕЛЬ", "D:\\МАЙ", "D:\\ИЮНЬ", "D:\\ИЮЛЬ", "D:\\АВГУСТ", "D:\\СЕНТЯБРЬ", "D:\\ОКТЯБРЬ", "D:\\НОЯБРЬ", "D:\\ДЕКАБРЬ", "D:\\TLG"]

Если нет: Обязателен; старое имя dirs

Рекурсивно индексируемые корни. Каталог может появиться позднее. У учётной записи службы должен быть доступ; буква сетевого диска пользователя не подходит.На учебном корне создайте разрешённый текст, дождитесь обновления и найдите уникальное слово.
excluded_subtrees

Массив абсолютных локальных или UNC-путей; [] допустим

Шаблон: ["D:\\TLG\\OUT"]

Если нет: []

Исключает сам указанный каталог и все вложенные. На Windows сравнение без учёта регистра и после нормализации пути; OUTSIDE не совпадает с OUT. Это путь, не маска имени.Учебный файл в исключённой ветке не должен индексироваться, в соседней — должен.
indexed_extensions

Массив строк без точки, краевых пробелов, *, ?, /, \ и дублей регистра

Шаблон: ["txt", "atl", "shp"]

Если нет: Обязателен; старое имя extensions

Сравнивает последнее расширение без учёта регистра: txt принимает FILE.TXT, но не file.mytxt. Пустой массив только вместе с include_extensionless_files=true.Сравните учебные file.txt и file.mytxt после полного обновления.
include_extensionless_files

true / false

Шаблон: true

Если нет: false для новых имён полей

Разрешает файлы без расширения, независимо от indexed_extensions; к ним относятся README и .hidden. Старый extensions может задавать это пустой строкой.На учебном корне проверьте отдельный файл без расширения.
query_word_match

Строка all / any

Шаблон: "all"

Если нет: any

all требует каждое целое слово запроса; any — хотя бы одно. Не SQL-точность и не точная фраза. Согласуйте правило у всех источников группы.Запрос из двух учебных слов: сравните документы с одним и обоими словами.
max_response

Целое 0…2147483647

Шаблон: 50000

Если нет: 30

Число лучших текстовых ответов одного сервера. 0 даёт пустой список; отрицательное при прямом старте тоже приводит к пустому ответу, мастер его отвергает. Не меняет SQL-лимит клиента.На учебной выборке больше лимита проверьте число строк одного источника.

ind_time

Целое число секунд ≥1

Шаблон: 1500

Если нет: 0; без исправления запуск не пройдёт

Период полного обновления active. В шаблоне 1500 секунд = 25 минут. В archive таймер не запускается, но допустимое значение всё равно требуется.По журналу index проверьте периодический проход, не по одному ответу PONG.
scan_on_startup

true / false

Шаблон: false

Если нет: true

Первый полный проход сразу после загрузки индекса в active. false оставляет ожидание таймера; слежение за файлами остаётся. В archive проход отключён.По журналу первого запуска проверьте наличие или отсутствие стартового прохода.
authentication_mode

Строка required / none

Шаблон и отсутствие поля: required

required — проверка токенов USB/ПК. none — общий доступ без ключей, токенов и базы разрешений. В журнале общее имя unauthenticated_user и IP. Меняется для каждого экземпляра; применяется после перезапуска и переподключения клиента.Выберите в клиенте «Без авторизации». Открытый сервер разрешит поиск; защищённый потребует токен. Порядок переключения и ограничения.
server_mode

Строка active / archive

Шаблон: "active"

Если нет: active

active включает слежение и периодическое обновление. archive отключает их и оперативную ARCHIVE.db3; требует document_catalog_storage=sqlite. Сам флаг файлы не переносит.Проверьте режим после перезапуска; перенос закрытого года выполняйте архиватором.
document_catalog_storage

Строка memory / sqlite

Шаблон: "sqlite"

Если нет: memory

Способ хранения каталога путей: RAM или SQLite. Индекс всегда inverted_index.sqlite. Архивирование службы требует sqlite. Исправная база сохраняет идентификаторы при смене режима.Перезапустите и откройте прежние учебные результаты. Новая установка мастером предлагает sqlite; при обновлении — установленный режим.
enable_prm_short_content_autodetect

true / false

Шаблон: false

Если нет: true

В active включает обработку новых файлов для описи, а у входящих также обновление краткого содержания PRM. Нужны включённый AutoPad-источник и разрешённый тип; путь с подстрокой OUT в любом месте пропускается. Это запись в базы, а не поиск. .zag обслуживает отдельный ZagEditor.Только в отдельном тестовом профиле сравните поле PRM до/после нового учебного файла; на рабочих данных для проверки не включайте.
hide_console_window

true / false

Шаблон: false

Если нет: false

Скрывает окно ручного консольного запуска. В режиме Windows-службы не меняет работу; при критической ошибке окно может показываться.В отдельном ручном профиле проверьте окно после запуска, не состояние службы.

prm_base_dir

Строка абсолютного локального каталога; пусто выключает PRM

Шаблон: "D:\\BASES"

Если нет: Обязательная строка

Корень входящих AutoPad. В active для текущего года сначала читается ARCHIVE.db3; для прошлого года она используется запасным источником, если месячных баз вообще нет. В active пустой корень отключает источник даже при заданном месячном каталоге. В archive источник остаётся включённым при непустом явном месячном каталоге.Выполните SQL-поиск Вх.; отсутствие месяца даёт неполную выборку, а не новый пустой файл.
prd_base_dir

Строка абсолютного локального каталога; пусто выключает PRD

Шаблон: "D:\\BASES_PRD"

Если нет: Обязательная строка

Корень исходящих AutoPad. В active пусто отключает источник; в archive достаточно явного месячного каталога. Индексация текста не зависит от этого пути, но выдача карточек текста пропускает выключенные AutoPad-источники.Выполните SQL-поиск Исх. по учебной базе.

prd_monthly_bases_dir

Абсолютный локальный каталог либо пустая строка

Шаблон: "D:\\BASES_PRD\\METH_BASES"

Если нет: prd_base_dir\METH_BASES; при выключенном PRD пусто

То же для исходящих. В archive используются месячные базы без ARCHIVE.db3.Проверьте учебную исходящую карточку соответствующего года.
opis_base_dir

Непустой абсолютный локальный каталог, без UNC

Шаблон: "D:\\OPIS_ADMIN"

Если нет: D:\OPIS_ADMIN

Служебная база описи ГОД.db/ГОД.DB. Это каталог, не полный путь файла. Отсутствие файла проявится при получении описи или записи в неё.Получите опись из клиента; локальный год имени не переключает серверную базу.
f12_base_dir

Непустой абсолютный локальный каталог, без UNC

Шаблон: "D:\\F12"

Если нет: D:\F12

Маршруты ГОД.db; base.db дополняет данные только для текущего календарного года. Клиентская use_f12 лишь открывает панель.Откройте путь известной учебной карточки; проверка PONG наличие маршрутов не подтверждает.
tlg_send_root

Непустой абсолютный локальный каталог, без UNC

Шаблон: "D:\\"

Если нет: D:\

Назначение загружаемых файлов на отправку; создаются подпапки месяца и даты. Содержимое архива поиска этим не переносится.Передайте отдельный учебный файл и проверьте его в ожидаемой папке и журнале.
razn_output_dir

Непустой абсолютный локальный каталог, без UNC

Шаблон: "D:\\OPIS_ADMIN\\РАЗНОСКА_ДЛЯ_ПРОСТАВЛЕНИЯ"

Если нет: D:\OPIS_ADMIN\РАЗНОСКА_ДЛЯ_ПРОСТАВЛЕНИЯ

Назначение файлов разноски; не корень индексирования.Передайте учебную разноску, проверьте журнал и конечную папку.

Производительность

Поле и допустимые значенияПример из шаблона / отсутствиеНазначение и связиПроверка после применения
thread_count

0 либо целое ≥2; мастер ограничивает числом CPU и архитектурой

Шаблон: 4

Если нет: 6

CPU-пул. 0 — автоматически по логическим CPU; 1 запрещён. Мастер рекомендует не более 8, максимум 2×CPU и 32 для x86 / 64 для x64. Не число сетевых потоков.Сверьте итог мастера и журнал загрузки; замеряйте время на одном учебном наборе.
max_parallel_readers

Целое ≥0

Шаблон: 0

Если нет: 0

Число одновременно читаемых файлов в обычном обновлении; 0 без лимита. Для учебного HDD можно сравнить 1. Отдельные batch-читатели задаются batch_reader_threads.Сравните время полного прохода и загрузку диска на одинаковом наборе.
file_indexing_timeout_sec

Целое 10…600 секунд

Шаблон: 120

Если нет: 60

Таймаут ожидания одного файла в полном проходе. Просроченное ожидание журналируется; проход продолжается. Это не сетевой таймаут клиента и не принудительное прерывание чтения.На контролируемом замедленном файле проверьте запись таймаута и продолжение прохода.
compact_threshold_percent

Число 0…100

Шаблон: 5.0

Если нет: 5.0

Порог доли пустых ячеек словаря для уплотнения после полного обновления. Не удаляет файлы и базы AutoPad.Проверьте журнал уплотнения после учебного обновления с изменениями.

Читающие потоки конвейера при batch и пустом индексе. На ежедневном пофайловом обновлении не действует.Сравните первую сборку одного учебного набора и нагрузку диска.

Если нет: 0

Шаблон: 2.0

Период записи накопленных изменений индекса. При прямом запуске ≤0 заменяется на 2; мастер требует >0. Штатная остановка выполняет сброс.Проверьте журнал записи и повторное открытие отдельного учебного индекса.
sqlite_mirror_max_pending_ops

Шаблон: 500

Если нет: 500

Запись при достижении порога операций; 0 — только по таймеру. Не число результатов поиска.На учебном потоке изменений проверьте журнал сброса до истечения таймера.

Шаблон: 4

Если нет: 4

Параллельная загрузка индекса при старте. 1 — последовательно; значение >16 внутри ограничивается 16. Мастер может предложить меньше по CPU.Сверьте эффективное число и время загрузки в журнале старта.
sqlite_precount_postings

true / false

Шаблон: false

Если нет: false

Предварительный подсчёт вхождений для выделения памяти. Сам требует дополнительного прохода; ускорение не гарантировано.Сравните старт одного учебного индекса с false и true; оставьте обоснованный замером режим.

Что подтверждает проверка

PONG подтверждает ответ процесса на порту. Он не подтверждает полноту индекса, наличие месячных баз, описи, маршрутов и возможность записи файлов. Проверяйте нужную функцию по последнему столбцу. Учебные проверки с изменением данных выполняйте в отдельном профиле, не в рабочем архиве.

Для SearchEngineService 0.1.99. Редакция 30 октября 2026 года. Все примеры учебные.
