НОВАЯ УСТАНОВКА
1. Распакуйте весь комплект на локальный диск. Не запускайте BAT из ZIP.
2. Проверьте год и пути data\Settings.json — это шаблон новой установки.
3. Для нового местного сервера текущего года запустите
   Local-Install-With-Auth.bat — с авторизацией,
   Local-Install-Without-Auth.bat — без авторизации и токенов.
   Запустите один выбранный файл; при запросе Windows подтвердите права.
   Для другого года, выбора параметров или обновления используйте
   Install-SearchEngineService.bat.
   Экземплярам на одном ПК нужны разные порты и каталоги данных.
4. Дождитесь итога, запишите службу, год, порт и client-endpoint.txt.
   При коде 20 первичная индексация не прошла: исправьте причину
   и выполните показанную команду повторения.
5. В клиенте выберите токен или «Без авторизации» по режиму сервера, задайте адрес и порт, подключитесь,
   найдите и откройте документ. PONG подтверждает ответ, а не полноту данных.

ОБНОВЛЕНИЕ
1. Завершите операции. Сохраните прежний полный portable-комплект.
   Определите фактические программу, рабочий каталог данных и внешние пути из настроек.
2. До замены обеспечьте согласованные копии внешних документов и баз.
   Копия программы продолжает ссылаться на эти общие данные.
   Для живой SQLite простой копии одного файла недостаточно.
3. Из нового полного пакета запустите Install-SearchEngineService.bat,
   выберите существующий экземпляр, обновление и "1 — полная копия".
   Назначение экспорта должно находиться вне заменяемых каталогов.
   Install остановит службу и сохранит application/data до замены.
   Экспорт только настроек/журналов не заменяет полной копии.
4. Проверьте итог и сохранённый экспорт, версию, вход, все нужные функции,
   документы и данные. Храните прежнюю установку и копии до окончания
   выбранного периода стабильной работы.
5. Для возврата сначала остановите новую версию. Порядок возврата и
   совместимость данных описаны в полном руководстве.
   Install рассчитан на стандартные ProgramFiles/ProgramData по имени службы.
   Для службы в архиве или под другим корнем сначала проверьте путь возврата;
   прямое обновление такого комплекта не предполагается.

НАСТРОЙКИ И УДАЛЕНИЕ
Рабочий JSON меняйте через Configure-SearchEngineService.bat:
выбор службы, редактор временной копии, проверка, подтверждение, перезапуск.
Клиентская Settings.db3 автоматически не меняется.

До Uninstall сохраните полную копию и прочитайте показанные пути.
Удаляются служба, программа и рабочие данные; у архивной службы —
активный архивный комплект с документами и базами.
Ключи и профильный токен удаляются отдельно; проверьте другие зависимости.

Полный комплект руководств в исходной распакованной portable-папке:
  tutorials\00_Все_руководства.html
  tutorials\Быстрые_действия\Установить_сервер.html
  tutorials\Быстрые_действия\Обновить_сервер.html
  tutorials\Быстрые_действия\Удалить_сервер.html
  tutorials\Батники\Установка_обновление_и_удаление.html
  tutorials\Настройки\Настройки_сервера.html
  tutorials\Подробные_руководства\Заморозка_и_архивация_сервера.html

HTML работают без интернета. Обязательные runtime-имена README.txt
и INSTALLATION_GUIDE_RU.txt сохраняются: Install копирует эти краткие
инструкции в установленную папку. Полный tutorials остаётся в portable.
ДВА РЕЖИМА ДОСТУПА
Мастер установки предлагает: 1 — с авторизацией, 2 — без ключей.
Local-Install-Without-Auth.bat не создаёт ключи и токен.
В рабочем Settings.json поле config.authentication_mode: required / none.
Отсутствие поля означает required; смена применяется после перезапуска.
В клиенте выберите «Без авторизации» и подключитесь. В журнале будут
unauthenticated_user и IP. Порт открыт всем допущенным сетью компьютерам.
Порядок: tutorials\Подробные_руководства\Работа_без_авторизации.html

БЫСТРАЯ УСТАНОВКА ОДНИМ ЗАПУСКОМ
Local-Install-With-Auth.bat — с авторизацией.
Local-Install-Without-Auth.bat — без авторизации, ключей и токенов.
Выбор режима не спрашивается. Подтвердите только запрос прав Windows.
Год и порт выбираются автоматически, индекс строится и служба запускается.
