SearchEngineService {{ARCHITECTURE}} — переносимый комплект
Минимальная Windows: {{MINIMUM_WINDOWS}}
Для SearchEngineService 0.1.99. Редакция 30 октября 2026 года.

Распакуйте и переносите комплект целиком: BAT, app, data, tools,
prerequisites и tutorials должны оставаться вместе.

Новое местное развёртывание текущего года:
  Local-Install-With-Auth.bat — с авторизацией.
  Local-Install-Without-Auth.bat — без ключей и токенов.
Запустите один выбранный файл, подтвердите запрос прав Windows при появлении.
Каждый создаёт только новую установку. Для обновления нужен Install.
Для другого года, выбора параметров и обновления:
  Install-SearchEngineService.bat — от имени администратора.

Перед обновлением завершите операции и сохраните прежний полный комплект.
В Install выберите существующий экземпляр и полный экспорт программы/data
вне заменяемых папок. Он выполняется после остановки службы, до замены.
Сохраните отдельно согласованные копии внешних документов и баз:
экспорт установки не включает автоматически пути из Settings.json.
Старый комплект и копии храните до проверки всех функций и стабильной работы.
Install рассчитан на стандартные ProgramFiles/ProgramData по имени службы.
Службу из архива или другого корня этим порядком вслепую не обновляйте.

После установки/обновления запишите имя службы, год, фактический порт
и путь client-endpoint.txt. Проверьте доступ, поиск и открытие документа;
RUNNING и PONG не подтверждают полноту индекса и остальных данных.

Начать с задачи в полной распакованной папке:
  tutorials\00_Все_руководства.html
  tutorials\Быстрые_действия\Установить_сервер.html
  tutorials\Быстрые_действия\Обновить_сервер.html
  tutorials\Быстрые_действия\Изменить_настройки.html
Все параметры:
  tutorials\Настройки\Настройки_сервера.html
Полный порядок установки, возврата и удаления:
  tutorials\Батники\Установка_обновление_и_удаление.html

Рабочий Settings.json лежит в фактическом рабочем каталоге данных выбранной службы.
data\Settings.json в portable — шаблон установки. Для изменения рабочего
файла используйте Configure-SearchEngineService.bat. Изменения применяются
перезапуском; подключение в Settings.db3 клиента исправляется отдельно.

Stop и Restart ждут штатную остановку до 1800 секунд без force-kill.
Uninstall полностью удаляет выбранную службу, её программу и рабочие данные.
Для архивной службы целью будет активный архивный комплект с документами
и базами. Сначала сохраните полную копию и проверьте конкретные пути.
Ключи издателя и профильный токен удаляются отдельным
Remove-SearchEngineAuthKeys.bat; они могут быть нужны другим службам.
Общий доступ и перевыпуск — Setup-Access.bat; смотрите подробные руководства.

Windows PowerShell нужен для списка служб, регистрации токена и проверки
пакета. Остальные компоненты поставляются с комплектом.
README.txt и INSTALLATION_GUIDE_RU.txt также копируются в установленную папку.
Полный tutorials установщик туда не копирует: открывайте HTML без интернета
из сохранённого полного распакованного portable-комплекта.
ДВА РЕЖИМА ДОСТУПА
Мастер установки предлагает: 1 — с авторизацией, 2 — без ключей.
Local-Install-Without-Auth.bat не создаёт ключи и токен.
В рабочем Settings.json поле config.authentication_mode: required / none.
Отсутствие поля означает required; смена применяется после перезапуска.
В клиенте выберите «Без авторизации» и подключитесь. В журнале будут
unauthenticated_user и IP. Порт открыт всем допущенным сетью компьютерам.
Порядок: tutorials\Подробные_руководства\Работа_без_авторизации.html

БЫСТРАЯ УСТАНОВКА ОДНИМ ЗАПУСКОМ
Local-Install-With-Auth.bat — с авторизацией.
Local-Install-Without-Auth.bat — без авторизации, ключей и токенов.
Выбор режима не спрашивается. Подтвердите только запрос прав Windows.
Год и порт выбираются автоматически, индекс строится и служба запускается.
